# Definition of Done

## Atomic gameplay task

Done only when:

- behavior implemented in correct layer;
- deterministic unit/scenario tests exist;
- relevant bounds/invariants remain protected;
- user-visible copy is complete in ko-KR and en-US;
- content validates;
- typecheck/lint/relevant tests pass;
- docs reflect behavior;
- progress/backlog updated.

## Milestone

Done only when:

- every milestone acceptance item is implemented or explicitly removed by approved decision;
- full required command suite for that milestone passes;
- E2E happy path passes in both locales for user-visible milestone flows;
- save/reload is verified for new state;
- simulation report shows no known catastrophic distribution issue;
- active exec plans are completed/moved;
- no critical/high blocker remains for milestone scope.

## 1.0 release candidate

Also requires `RELEASE_CHECKLIST.md` completion.
