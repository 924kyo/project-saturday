# Acceptance Scenarios

These are behavioral stories to turn into deterministic scenario/E2E tests as milestones arrive.

## A — Bilingual first screen

Given a fresh install, switching between `ko-KR` and `en-US` changes all visible shipping copy without missing keys or layout breakage.

## B — Weekly training loop

Create a WR, select three weekly actions, resolve them, advance week, reload browser, and recover the same validated state.

## C — Skill build changes choice value

Two identical seeded WR states differ only by equipped skill. Weight training or Film Study should produce the documented different result; UI explanation should surface the relevant modifier.

## D — Depth promotion

A WR begins below the rotation. Through training/practice/trust, evaluation crosses a stable promotion threshold and projected snaps increase. Re-running with same seed/actions reproduces the result.

Automated in M3: a literal browser seed commits the same five-offer shortlist and seven-player room in both locales, then the same Extra Practice / Route Drills / Recovery week moves the player from WR6 to WR5 and projected snaps from 12–30% to 20–40%. Core scenarios and the checked-in 60-career depth report also cover held movement, demotion, and zero adjacent-week reversals.

## D2 — M3.5 experience foundation

Create an athlete in either locale and verify that appearance changes update one persistent graphical identity. Navigate Home / Week / Team / Skills / Player at 320 px and desktop widths. Commit three focus blocks under two otherwise identical deterministic careers: a development-heavy path and a Preparation/Confidence/role path must produce different explainable practice, trust, or opportunity consequences without either reducing to Body-only optimization. Attribute and proficiency progress must state the next threshold. Team must explain current rank, projected participation, the nearest relevant competitor, and actionable gaps. Pointer clicks leave no persistent keyboard-style outline; keyboard traversal retains visible focus. First-visit help can be skipped and replayed.

## E — Key-snap information

Preparation, Film Study/high Football IQ, or an appropriate skill exposes additional coverage/leverage information on an eligible key snap without directly forcing success. Across representative WR1–bench roles, decision counts stay in the specified bands and every game provides truthful role-appropriate participation feedback.

Automated in M4: core scenarios separate clue visibility from six-draw resolution and exercise every decision family/hook; the checked report covers 120 games and every depth role. Korean/English production-browser journeys persist preview, two-key-snap opportunity, failed-save exact retry, post-game grade/stats/participation/history, reload, and next-week advance on mobile/desktop, with a dedicated 320 px containment and 72 px decision-target path.

## F — Full vertical-slice season

Create player → choose program → camp → weekly season → games/events/cards/depth → postseason/end → alumni saved → start second career and see persistent legacy history.

Run scenario F in both locales by M5.

Automated in M5: component/integration coverage exercises every saved season surface in Korean and English: bootstrap and calendar context, standings, event effects, injury opportunity caps and both choices, postseason handoffs, complete review evidence, persistent portrait, atomic alumni completion, failure focus/lockout/exact retry, exact final session/meta reload, and returning-history Creation. Five production-browser careers complete the full shipping flow in Korean/English on native mobile/desktop plus 320 px, resolve deterministic event and injury branches, reload online and offline at authoritative decisions, prove the final session/meta transaction is all-or-nothing, publish one alumnus, and create a distinct second athlete that sees the prior history without inherited power.

After M6 activates multi-season play for new v6 careers, the preserved M5 production-browser journeys still complete camp, regular season, postseason, deterministic event/injury branches, online/offline reload, and exact review persistence, then stop at the authoritative v6 offseason handoff. The original atomic alumni/second-career ending remains covered for completed or migrated v5 careers by component, command, migration, and storage tests; it is not incorrectly invoked for a new returning v6 athlete.

## G — Failed career still persists

A low-opportunity/poor-outcome career ends without star status; alumni/history and bounded legacy discovery are still saved.

## I — Current four-position career and long-history persistence

Create each supported athlete through the actual bilingual UI. Make independent weekly choices, select a four-slot build, resolve real event/injury/NIL and snap decisions, and read position-owned grade/stat/XP/trust consequences. A zero-opportunity game must explain its actual role without inventing stats. Transfer, reload and recover into the destination's Team view, preserving original identity and prior history. Use the Career Hub to start another run while keeping earned alumni/settings; failed New Career must retain the exact recoverable career and proof.

Added-position native careers pin UUID suffixes 1–6 and traverse two seasons with Film/Recovery/Study and first available life decisions. Read-only IndexedDB inspection verifies the exact envelope at reload/retry boundaries, strict sub-1 MB bytes, one first-season offseason choice, two completed summaries and the identical final alumni envelope. Completed-New-Career must satisfy the existing five-second UI expectation. The profile matrix additionally covers both Stay/transfer branches for both seed sets and the original training policy: eighteen completed paths, 3,155 exact whole-domain reloads and unchanged codec/time limits. Literal v1/v2 records load without eager rewrite, then the next successful current command writes envelope v3; older writers cannot replace it. Final M7 verification passes all 88 applicable native executions (two intentional mobile-only skips), including all twelve added-position two-season paths.

## J — M7.5 tactical experience correction (required before M8)

For QB/RB/WR/CB, inspect context and a beginner-readable choice, preview without submitting, resolve and save one chosen snap, then view a deterministic board/animation and actual consequences. Skip, reduced motion, replay and reload cannot reroll or advance gameplay. Earned information stays earned; hidden defenders and absent historical context cannot be fabricated. A post-game story shows real score, participation, defining moments, coach/development consequences and only triggered reactions. Repeat at 320 px and desktop in both locales, offline and across failed-save retry. These are required acceptance criteria, not a claim that the Tactical Snap Board is implemented.
