# Content QA

## Every content batch

Check:

- stable unique IDs;
- valid references;
- both locales complete;
- requirement tags are reachable/plausible;
- effects are supported by engine registry;
- no accidental exact copies of real-school/proprietary wording or identities;
- tone consistency;
- no misleading choice consequence text;
- no dominant near-duplicate cards/events solely differing by numbers.

## Event review

For each event ask:

- Why can this event happen to *this* player?
- Does at least one choice create a meaningful tradeoff/expression?
- Would the event feel noticeably different if shown to every player regardless of identity? If yes, strengthen requirements.

## Skill review

For each card ask:

- Does it alter a decision, information state, system efficiency, or risk?
- Is grade/power budget appropriate?
- Is it a strict redundant upgrade of another card?
- Does it create or support a build?

## Program review

For each fictional program ask:

- Is the archetype legible?
- Is it an original composite rather than a renamed real school?
- Does its gameplay profile create a distinctive career decision?

## Game-pattern review

For each key-snap batch ask:

- Does every pattern present exactly three athlete-level choices from its owning family?
- Do paired contexts reverse the best fit instead of creating one universal answer?
- Do coverage and leverage clues describe the persisted hidden context exactly?
- Are Body, Preparation, Confidence, role scarcity, and risk represented through named mechanics rather than copy-only claims?
- Are names, situations, writing, rules, and mechanics original rather than traced from a reference game or real program?
