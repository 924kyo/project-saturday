- Content minimums favor a smaller mechanically live set over filler. The counts may increase after report/playtest evidence, but no position ships with renamed WR decisions or untranslated placeholders.
- Position-neutral common skills/events/actions remain common only after validation proves the effect applies. A shared label is not evidence of shared mechanics.
