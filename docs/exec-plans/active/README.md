# Active Exec Plans

Codex creates feature/milestone plans here before broad multi-module work.

Naming examples:

- `bootstrap.md`
- `skill-system-v1.md`
- `depth-chart-v1.md`

When a plan is fully verified, move it to `../completed/` and update `PROGRESS.md`.

Minimum sections:

- Goal
- Scope
- Non-goals
- Relevant specs
- Proposed steps
- Acceptance criteria
- Test/verification plan
- Risks/assumptions
- Progress notes
