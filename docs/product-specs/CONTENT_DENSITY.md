# Content Density Targets

Quantity follows systems, not the reverse.

## Vertical slice (WR, 12 programs, one season)

Target ranges:

- 12 fictional programs
- 1 playable position (WR)
- 3 WR archetypes
- 5 recruiting backgrounds
- 8 personality traits
- 36+ skill cards
- 50–70 events
- 9+ weekly action definitions
- 8–12 NIL offer templates only if NIL is in the target milestone
- 8–12 injury/recovery outcomes if injuries are enabled
- 6–10 key-snap decision patterns
- basic regular season + postseason path
- complete ko-KR/en-US copy for all shipping content

## 1.0 direction

- 96 programs
- 8 conferences
- 6 playable positions
- ~18 position archetypes total
- 100–130+ skill cards
- 250–350 high-value authored events
- 40–60 NIL deal types/templates
- 25–30 injury types/severities/rehab patterns
- 60–80 football concepts/key-snap patterns across positions
- 25+ awards/major career achievements
- robust postseason, record book, draft, alumni history

## Reuse philosophy

Prefer conditional recombination over 1,000 generic events.

A 300-event library where each career sees a context-dependent subset is better than 1,000 events that ignore identity.
