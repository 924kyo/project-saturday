# Position Design

## Shared principle

Each playable position uses the same career framework—training, cards, Body, depth competition, events, games, legacy—but must create distinct football decisions.

Do not solve position differentiation by changing only stat names.

## WR — Vertical Slice

Position attributes:

- Release
- Route Running
- Hands
- Catch in Traffic
- YAC
- Blocking

Key decisions:

- release technique;
- route stem/leverage response;
- catch approach;
- YAC vs ball security.

## QB

Position attributes:

- Throw Power
- Short Accuracy
- Intermediate Accuracy
- Deep Accuracy
- Pocket Presence
- Read Progression

Common physical/mental attributes still apply.

Key decisions:

- pre-snap shell/read;
- first/second read choice;
- pressure response;
- checkdown vs aggressive throw;
- scramble/extend play when profile permits.

QB must not require the user to call every team play. The simulation/coordinator provides play context; the user makes athlete-level reads.

## RB

Position attributes:

- Vision
- Ball Security
- Contact Balance
- Elusiveness
- Receiving
- Pass Protection

Key decisions:

- press/cut chosen gap;
- bounce vs take available yards;
- finish run vs protect body/ball;
- pickup/blitz recognition;
- route/catch/YAC choice.

## CB

Position attributes:

- Man Coverage
- Zone Coverage
- Press
- Ball Skills
- Tackling
- Recovery Technique

Key decisions:

- press/off leverage;
- release response;
- route break/read;
- play ball vs secure tackle;
- zone handoff/drive decision.

## LB

Position attributes:

- Run Recognition
- Zone Coverage
- Man Match
- Tackling
- Block Shed
- Blitz Timing

Key decisions:

- run/pass key;
- gap fit;
- zone depth/drive;
- blitz lane/timing;
- tackle security vs big-hit attempt when supported.

## EDGE

Position attributes:

- Get-Off
- Speed Rush
- Power Rush
- Counter Move
- Edge Setting
- Tackling

Key decisions:

- speed/power/counter rush;
- contain vs chase;
- read option responsibility;
- finish/strip-sack risk choice.

## Position-specific content

Each position eventually needs:

- distinct training actions;
- at least two or three archetypes;
- position skill cards and common cards;
- key-snap templates;
- position room/depth events;
- performance grading logic;
- coach evaluation weights.

## Initial archetype direction

- QB: Field General / Gunslinger / Dual Threat
- RB: Power Back / Elusive Back / All-Purpose
- WR: Deep Threat / Route Technician / Possession
- CB: Press Man / Ball Hawk / Zone Technician
- LB: Run Stopper / Coverage Backer / Hybrid Blitzer
- EDGE: Speed Rusher / Power Rusher / Edge Setter

These are starting design labels and may be renamed editorially while stable IDs remain migration-safe.
