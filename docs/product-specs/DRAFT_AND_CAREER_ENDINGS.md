# Draft and Career Endings

## Naming/licensing

Use **Pro Draft** and fictional professional framing by default. Use of real league branding requires separate legal/licensing review and is outside the autonomous default.

## Draft stock dimensions

Draft evaluation can consider:

- athletic traits/size;
- position skill ratings;
- production;
- level of competition/program exposure;
- big-game performance;
- durability/injury history;
- awards;
- consistency;
- combine/pro-day style evaluation where implemented.

Avoid making Overall alone determine draft result.

## Declaration

When eligible in the fictional ruleset, the player may face a decision:

- declare for pro draft;
- return for another college season, if career eligibility remains.

Show projected range with uncertainty, not guaranteed exact pick.

## End states

Possible endings include:

- drafted early;
- drafted late;
- undrafted/pro opportunity abstracted;
- college career complete without pro path;
- career-ending/retirement story;
- user chooses to end career when appropriate.

Every ending produces an Alumni record.

## Final career presentation

M7.5 B1c full-life profiling exposed that WR second-season play lacks a valid terminal review/retirement boundary; this is a required B6 defect, not an accepted asymmetry. Add a versioned two-season review and completion while preserving all literal historical single-season saves and alumni. Review must distinguish each season's production from career totals, preserve both program stints and archived world results, and retain all available first-season summary evidence. Do not synthesize missing historical injury outcome IDs or relabel a two-season career as a one-season ending. Current schema/writer activation and actual bilingual UI acceptance remain separate mandatory gates.

Show:

- program(s);
- seasons;
- stats;
- awards;
- championships;
- best games/records;
- signature skill build;
- draft/ending;
- persistent legacy rewards/unlocks.

The ending should feel like closing a character story, not merely returning to title screen.

## M5 vertical-slice ending

The current M7 added-position alpha presents actual saved season statistics, starting/final rank and role, injury-unavailable weeks and the end-of-season equipped build. Current second-season review has an explicit retirement action, not a third program selection; completion displays the persisted alumni career totals, championship count and athlete visual identity, with a return to Career Hub. A neutral historical v1 save paused at its old final offseason decision keeps that original selected-option transition with a clear legacy explanation and no additional played season. Neither path fabricates a pro draft result; later draft content must remain versioned.

M5 closes the first playable career after one complete college season with the stable ending ID `career_ending_one_season_complete`. It does not imply draft eligibility, evaluate pro stock, or fabricate a return/transfer decision. The player first enters an explicit season-review phase containing the program record and rank, postseason outcome, player totals and average grade, best game, starting/final role and trajectory, skills, and injury history. Confirming that review creates the Alumni record and moves to an explicit completed phase.

This bounded ending lets stars, role players, injured careers, and non-qualifiers all produce truthful history. Later declaration, return, transfer, and pro-draft paths must add versioned outcomes and migrations rather than reinterpret an existing M5 alumnus.
