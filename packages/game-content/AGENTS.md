# AGENTS.md — packages/game-content

This package contains data-driven game content and localization resources.

## Hard rules

- Mechanics use stable IDs; display names are never identifiers.
- Every user-visible content string has both `ko-KR` and `en-US` entries.
- Content must pass schema and reference validation.
- Avoid 1:1 imitation of real university logos, nicknames, slogans, colors, traditions, stadium names, or proprietary game text.
- Fictional programs should feel culturally legible through archetypes while remaining original composites.
- New content must declare tags/requirements explicitly so event and skill pools remain analyzable.
- Do not add dozens of low-value variants solely to hit quantity targets.
